The Roldr action button — radius 12px, padding 12/18, 44px minimum tap target.

```jsx
<Button variant="primary" icon="dices" fullWidth>Unirme a la mesa</Button>
<Button variant="secondary">Ver ficha</Button>
<Button variant="ghost" size="sm">Ahora no</Button>
```

Variants: `primary` (100° brand gradient, white 700 label — **one per screen**), `secondary` (surface-raised), `ghost` (transparent, hover = white 8%), `danger` (outlined red, destructive only). Press = scale .97; hover = brightness 1.08.
