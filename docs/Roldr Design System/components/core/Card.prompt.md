Default Roldr surface — use for list rows, panels and modal bodies.

```jsx
<Card>
  <h3 style={{ font: 'var(--text-title-2)' }}>La Tumba de Aniquilación</h3>
  <p style={{ font: 'var(--text-caption)', color: 'var(--text-muted)' }}>D&D 5e · Jueves 20:30</p>
</Card>
```

`raised` for anything floating above another card; `ambient` only for a hero panel (one per screen).
